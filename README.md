# Diagram Studio

Браузерный редактор диаграмм: React 19, TypeScript 6, Vite 8, React Flow 12, Zustand 5, Tailwind 4. Работает без регистрации и backend API. Сейчас доступен IDEF0; блок-схемы и ERD представлены в меню как «Скоро».

## Запуск

Требуется Node.js **24.13+ в ветке 24 LTS** (версия задана в `.nvmrc` и `package.json`).

```bash
npm ci
npm start
```

Откройте **http://127.0.0.1:5173/**. Сервер должен оставаться запущенным в терминале. `npm run dev` запускает тот же редактор. Порт фиксирован: если занят, Vite сообщает об ошибке, а не переходит незаметно на другой адрес.

### Если браузер сообщает connectionfailure

1. Запустите `npm start` из каталога проекта и проверьте вывод терминала.
2. Используйте `http://127.0.0.1:5173/` (HTTP, не HTTPS).
3. После обновления зависимостей остановите прежний сервер и запустите `npm run dev -- --force`, затем обновите страницу.
4. Если порт занят, остановите старый сервер этого проекта. Не завершайте неизвестные процессы.
5. Для другого устройства используйте сетевой адрес компьютера из вывода Vite. Локальное хранилище на этом устройстве будет отдельным.

`localhost`, `127.0.0.1` и сетевой IP — разные адреса хранилища браузера. Чтобы увидеть прежние проекты, открывайте тот же адрес, что использовали ранее.

## Возможности

- стартовая страница со списком локальных проектов, созданием, импортом и удалением;
- несколько независимых IDEF0-моделей и их декомпозиций в одном проекте;
- дерево диаграмм, вкладки и хлебные крошки; закрытие вкладки не удаляет диаграмму;
- сворачиваемые боковые панели, отдельная палитра, инспектор и нижняя панель проверки;
- автосохранение в IndexedDB после завершённых операций с отображением результата и повтором при ошибке;
- сохранение масштаба и положения холста отдельно для каждой диаграммы;
- undo/redo: одно перемещение, изменение текста или удаление группы — одно действие;
- редактирование имени функции на холсте, копирование/вставка, дублирование и выравнивание выделенных блоков;
- прямоугольные маршруты стрелок, настройка смещения маршрута в свойствах;
- JSON, PNG, самостоятельный векторный SVG и векторный PDF; весь проект можно выгрузить в многостраничный PDF;
- кириллица в экспорте: локально включён Noto Sans под SIL OFL, лицензия в `public/fonts/OFL.txt`.

Горячие клавиши: Ctrl/Cmd+S — скачать JSON; Ctrl/Cmd+Z — отменить; Ctrl/Cmd+Shift+Z — повторить; Ctrl/Cmd+C/V — копировать/вставить; Ctrl/Cmd+D — дублировать; Delete — удалить. В текстовых полях работают обычные текстовые команды. Enter или уход из поля применяет подпись, Escape отменяет ввод.

Копирование переносит выбранные блоки и связи между ними, без вложенных декомпозиций. В контекстной диаграмме допускается одна функция. Корневую диаграмму проекта удалить нельзя; удаление остальных диаграмм с потомками можно отменить.

## Данные и совместимость

Проекты хранятся в IndexedDB `diagram-studio`, object store `projects`. `localStorage` содержит только настройки рабочей области (вкладки, панели, масштаб).

При первом открытии старый черновик `ulstu-idef0:last-project` проверяется и переносится в IndexedDB. Исходник удаляется только после успешной записи; существующий проект не перезаписывается. Повреждённый черновик сохраняется с сообщением об ошибке.

Формат JSON имеет версию `2.0.0`, диаграммы содержат `type: "idef0"`. Импорт версии `1.0.0` поддержан с автоматической миграцией. Проверяются структура, идентификаторы, ссылки и циклы декомпозиции. Неизвестные версии отклоняются. Импорт создаёт отдельную копию проекта и не перезаписывает существующий.

Скачивайте JSON для резервных копий: очистка данных браузера удаляет локальные проекты. Проект хранится на устройстве; облачной синхронизации и совместного редактирования нет.

## Архитектура

- `src/types/project.ts` — общая оболочка проекта и каталог нотаций; данные IDEF0 остаются в отдельном типе.
- `src/features/project` — проверка файлов, миграции, IndexedDB и состояние рабочей области.
- `src/features/diagram` — модель операций с историей на Immer, преобразование в React Flow и редактор IDEF0.
- `src/features/export` — генерация SVG из модели и экспорт в PNG/PDF без снимков HTML.

История хранит неизменяемые версии с совместным использованием неизменённых объектов. Текущее перетаскивание и измерения React Flow живут отдельно от сохранённой модели и фиксируются в конце жеста.

Новые нотации нужно добавлять отдельными типами и адаптерами элементов, свойств и валидации, не расширяя IDEF0 необязательными полями. Заглушки не создают пустые псевдодиаграммы.

## Проверки

```bash
npm run lint
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют установленный Microsoft Edge на Windows; на других ОС сначала выполните `npx playwright install chromium`. Сценарии запускаются в изолированных профилях и не изменяют ваши проекты.

TypeScript оставлен на последнем исправлении ветки 6: установленный typescript-eslint пока требует TypeScript ниже 6.1. Обновлять до 7 следует вместе с поддерживающим его линтером.

## Docker и публикация

```bash
docker compose up --build -d
```

Адрес контейнера: **http://localhost:8080/**. Сборка использует Node 24 LTS, раздача — nginx stable. Для проверки production-сборки без Docker: `npm run build`, затем `npm run preview` и http://127.0.0.1:4173/.

Workflow публикации образа в GHCR остаётся в `.github/workflows/publish-container.yml`. Проверки кода и браузерных сценариев запускаются отдельным CI workflow.

## Ограничения

Блок-схемы и ERD пока недоступны для создания. Ветвление/слияние IDEF0-стрелок через junction-узлы ещё не реализовано. Смещение маршрута не заменяет свободное редактирование всех точек изгиба. PDF размещает каждую диаграмму на одной странице A4; очень большие схемы уменьшаются. В экспорте длинные подписи блоков переносятся и при нехватке места сокращаются многоточием. Основной сценарий интерфейса — работа на компьютере.
